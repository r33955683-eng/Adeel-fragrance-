ADEEL FRAGRANCE ADMIN PANEL

Open index.html in a browser.

IMPORTANT:
This version is a simple browser-based admin panel. Products, photos and WhatsApp settings are stored in the same browser/device using local storage.

It is excellent for testing and personal/local use. If you want a true online shop where changes made from an admin panel appear to every visitor, you need online database + hosting (for example Firebase/Supabase or another backend).

HOW TO USE:
1. Open index.html.
2. Go to Products.
3. Add Product.
4. Choose a photo, enter name/price/notes.
5. Save.
6. Go to Store Preview.
7. Settings lets you change the WhatsApp number.

The current sample products can be edited or deleted.
